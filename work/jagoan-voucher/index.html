Jagoan Voucher.

A marketplace, with a creator side.

Jagoan Voucher combines two product flows: buying game vouchers and supporting creators. Each needs a clear interface, while orders, balances and realtime updates depend on the backend behind it.

The product

The marketplace covers product selection, checkout and order status. Creator-facing tools include donation views, a dashboard and an Overlay Studio for configuring OBS browser-source widgets.

The overlay tooling includes alert and goal interfaces, with additional widgets for creator use. A demo state is separate from a live donation or payment.

My contribution

I worked on the frontend and backend. The scope spans the web interfaces and the application services supporting the marketplace and creator tools.

For the portfolio, the useful example is the connection between a product page, its order flow and the tools a creator uses after signing in.

Selected product flows

  • Search and product discovery in the marketplace.
  • Denomination selection, checkout and order tracking.
  • Creator dashboard and donation views.
  • Overlay Studio and OBS alert configuration.
  • Realtime interfaces supported by backend services.

For a similar project

This project is relevant to a business commissioning a marketplace or creator platform with several user roles and realtime interactions.

The frontend and backend need to agree on order states, balances and user roles. The marketplace and creator interfaces show different parts of that shared product.
